# Schedules from private Chat

A qualified private Chat without native scheduling can propose a Matrix schedule in conversation. Matrix prepares its execution identity from the current owner, Computer and source Chat. No Bot setup, destination choice, or Settings switch is required. Claude Code continues to schedule through its native feature.

## Trust and lifecycle

The Gateway resolves the source from the live registered run and existing tool authority. The scheduler reserves a purpose-specific, private execution binding for that origin. The existing canonical Bot executor verifies the binding and approved model source and runs the durable occurrence. Task approval and integration permissions stay independent of tool-call confirmation. Matrix never copies permissions or instructions from a user-created Bot.

The durable binding is internal. Public Chat and Bot APIs reject it, and list, search and navigation views omit it. The exact operation challenge can be read by its owner from the existing Chat card. Its view names Matrix Schedules and the source Chat. The signed decision still covers the full private binding and is revalidated against the live source. The Terminal inbox omits these challenges. An owner can review and manage the schedule from the original Chat and Schedules. The review stays anchored to the turn that proposed it. Actual outputs appear in committed conversation order.

Existing accepted requests retain their original target. Terminal, delegated Bot, and native Claude scheduling keep their current behavior. A removed or invalid binding cannot be replaced automatically. The reserved identity is reused after incomplete provisioning. An owner-scoped cap bounds retained execution contexts independently of the ordinary Bot inventory.

## Rollback

Bot schema v17 is additive. Older Gateway versions refuse to start Bot services against it and lack the public filters for its new internal Chats. Recover with a schema-aware build that retains the filters, and pause or archive QA schedules before reverting behavior. Do not downgrade the Gateway to a pre-v17 build after enabling this feature.
