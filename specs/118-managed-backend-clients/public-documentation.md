# Updates and supported apps

Matrix OS maintains your cloud computer's backend automatically. You do not need
to pick a backend version or update channel. Updates roll out gradually and can
briefly reconnect your session. Your files, account, apps and preferences remain
yours and are preserved during system updates.

The installed desktop and mobile apps update separately. Matrix OS recommends
new versions and, when an older app is no longer compatible, asks you to update
before continuing. The update screen provides an installer or app-store link.
An ordinary feature release does not necessarily make your installed app obsolete.

If an update needs a restart, save your work and follow the app's update prompt.
Mobile store updates may require confirmation from your device. Very old mobile
versions cannot receive over-the-air patches and need an app-store update.

If your cloud computer does not update or your app cannot install the required
version, contact support. Support can temporarily enable backend version controls
while investigating. You do not need to change these settings yourself.

Self-hosted installations retain their own update controls.
