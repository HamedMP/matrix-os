## CodexBar

[Repository and MIT license](https://github.com/steipete/CodexBar), [provider architecture](https://github.com/steipete/CodexBar/blob/main/docs/providers.md), [Codex scanner](https://github.com/steipete/CodexBar/blob/main/docs/codex.md), [Claude coverage](https://github.com/steipete/CodexBar/blob/main/docs/claude.md).

Useful design: separate quota windows from local API-equivalent estimates and billed spend; explicit timezone, coverage, unknown-price counts, native-session deduplication and model/provider separation. Local scans can work without credential access. Its Swift application is a reference, not a new Matrix runtime dependency. No source code copied. Its extensive adapters need per-source qualification; a quota-only provider cannot populate a historical token heatmap.

## Paxel source access and privacy

[Official portal](https://paxel.ycombinator.com/), [public launcher source](https://paxel.ycombinator.com/upload.sh), [official data handling](https://paxel.ycombinator.com/data-handling). The launcher is publicly readable and was downloaded only for inspection. It names `ghcr.io/yc-software/paxel-client:latest` and supports building from a local `PAXEL_REPO_ROOT` / `Dockerfile.client`. A repository search for Paxel under yc-software returned no repository visible to this connection. The analysis/scoring source and its license have therefore not been obtained or verified. Public client distribution is not proof of an open-source license.

The current official page lists Claude Code, Codex CLI, Cursor, OpenCode, Gemini CLI, VS Code Copilot and Antigravity. The data-handling document says the output includes narratives, selected prompt excerpts, session events with paths/commands, git metadata and redacted decisions; excerpts also travel through its model proxy. This is broader than token-only telemetry. We did not execute the launcher, install its skill, authenticate, pull/run the image or upload any user material.

Transferable concepts: multi-session streams, steering traces, evidence-backed recommendations and longitudinal changes. Do not copy opaque scoring or present archetypes as validated productivity measurements. Matrix should retain owner control and require consent for content analysis.
