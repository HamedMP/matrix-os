# Personalize Matrix

New installations open in the Matrix theme in light mode. An existing saved appearance is kept when you update.

Open **Settings → Appearance** to choose a theme and select **Light**, **Dark**, or **System**. System follows your device's appearance. Every preset offers both light and dark variants.

Choose an **Interface font** for the app and a **Code font** for editors. These choices are kept when you switch themes. Terminal windows keep their separate terminal settings.

To make your own theme:

1. Select **Create custom theme** and choose a base preset.
2. Use **Edit light** and **Edit dark** to set each version's background, panels, text, buttons, and borders.
3. Check the preview and select **Save custom theme**.

Matrix adjusts text contrast for readability. **Reset light colors** or **Reset dark colors** restores that version to its base preset in the editor; save to apply it. Your custom theme stays available when you try other presets.

These controls are shared across Web Canvas, Web Desktop, and Electron Desktop. Native Mobile continues to use its platform appearance controls.
