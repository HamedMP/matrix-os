## Host contract

Serve over the prototype's local HTTP server and embed `./demos/<id>/index.html` at the intended phone width, using **`sandbox="allow-scripts allow-forms"`**. `allow-forms` lets actual React form submit handlers run; it does not authorize native submissions. Preserve CSP form-action `none` and connect-src `none`, so native form navigation/POST and scripted network calls remain forbidden. Do not add `allow-same-origin`, downloads, popups, top navigation, or any parent/native owner bridge. The parent must reject privileged messages from this demo frame. A directly opened local page is useful for inspecting the UI but does not prove the sandbox boundary.

The existing Vite bundle contains no module import/export statements or `import.meta`; `verify.mjs` compiles it as a classic script. It is loaded as a classic deferred script without `crossorigin`. This avoids the ESM CORS requirement for an opaque (`null`) iframe origin. The stylesheet likewise has no `crossorigin` attribute. No wildcard CORS or `Origin: null` allowance is needed. Preserve the iframe's opaque origin and verify actual browser loading/console/CSP behavior before claiming the hosted prototype works.

Each HTML has a CSP denying all network connections, objects, base URLs, native form navigation/submission, nested frames, workers, fonts and images. A per-document nonce authorizes only the three local external scripts. Local styles plus style attributes are allowed for the unchanged starter's charts/layout. All JS/CSS assets are local and stored once. `frame-ancestors` cannot be enforced through a meta CSP; the parent iframe sandbox and production response-header policy are distinct controls.

The adapter exposes **only** a frozen `MatrixOS.db` with bounded in-memory record reads, insert, compare-and-swap and change subscriptions. Unconditional update fails. It has no integrations, generate, gateway fetch, proxy, filesystem, navigation or owner transport capability. It rejects non-record tables, duplicate inserts, stale comparisons, rows over 40 KB, more than 200 rows or eight subscribers. Page teardown clears state/subscribers. Native network constructors/fetch/open are disabled as additional guardrails; CSP is the browser network boundary. Anchor navigation/export is prevented; the host must keep its restrictive sandbox.

Meaningful preview interactions include search/filtering, financial period/currency views, date selection, record details, create/edit/archive and temporary save/reopen within the loaded document, project lanes and the Focus timer. Imports and real persistence are intentionally unavailable. A demo-only wrapper replaces only the exact import-unavailable desktop notice in `.main-column > main > p.notice[role="status"]` with “Example data. Changes reset on reload. Install to import from your tools.” It leaves genuine errors and every button/action unchanged, including the local Check records reload. No fake `generate` or `integrations` capability is added. The child-list observer is capped at 2,000 callbacks and 30 minutes, scans at most eight exact notice elements, and disconnects on page teardown. It does not observe character-data timer ticks or conceal content through CSS. Existing owner-save wording remains part of the actual UI; the always-visible banner clarifies temporary preview data. This does not satisfy the launch spec's polished mobile copy, bespoke workflows, production isolated demo origin, owner PostgreSQL round trip, or Native Mobile verification requirements.

## Verification

Run the dependency-free check from this directory with Node 24: `node verify.mjs`. It checks fixture reset, cloned reads, insert, atomic comparison success/conflict, subscription bounds, unavailable privileged capabilities, classic-script syntax, exact notice adaptation without changing genuine errors/local reload, observer cleanup, the documented scripts/forms-only opaque-origin host contract, and all eight bounded demo documents including form-action/connect-src denial. Browser rendering, phone interactions, parent-frame isolation and network/console inspection remain the prototype host's integration check; no production preview isolation claim is made here.

The isolated local Chrome browser check reported 16 fixture runs (eight apps at 360 and 390 CSS pixels): actual create/save, local Check records, reopen/edit and reload reset passed using physical browser clicks, without synthetic submit handlers. Each frame retained origin `null`; parent document and localStorage access threw SecurityError, and only MatrixOS.db was exposed. All 16 attempted real native form POSTs were blocked by the unchanged form-action policy, with zero POST/external requests and zero JavaScript errors. This is prototype fixture/host evidence, not production preview or Native Mobile evidence.
