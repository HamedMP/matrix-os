# Share a project with your organization

Project sharing gives collaborators access to every current and future Chat and project-owned item in that project. Each Chat remains one group AI timeline with named human prompts and shared AI responses.

The first time you share, Matrix defaults General access to **Everyone in your organization · Editor**. Editors can prompt AI and make authorized project changes on the owner's runtime. Viewers can read shared history but cannot compose or mutate project content. You can later change General access to Editor, Viewer, or Restricted and add, change, or revoke direct member access.

Organization membership alone is not project access, including for organization admins. A member needs both current Clerk membership and a project grant, and organization-wide access activates when that member first opens the project.

Public Chat snapshots are separate read-only publications. They do not grant project access. New standalone live shares for Chats, terminals, files, folders, or apps are unavailable; existing legacy shares remain readable and their owners can still manage or revoke access.

Files stay inside the project's authorization boundary, but this release does not add a collaborator file browser or editor. Project collaboration is available on Web Canvas, Web Desktop, and Electron Desktop.
