## Conversational setup

Agents **+** opens the existing chooser. **Start from scratch** opens a full-page setup Chat immediately. **Set up bot** opens the same Chat with the selected Recipe and version. Show its existing Skills, integrations and MCP requirements when declared. A setup turn asks one short question with a few short suggested replies, or proposes a draft for review. Show the latest change first; let the owner expand instructions, Skills, Sources and access details on demand. The owner's free-text reply and a clicked suggestion follow the same private Chat route. A setup Run ends once the gateway accepts its structured question or records its proposed draft for owner review. The preview derives the change summary from the proposed fields. The owner can continue the conversation or explicitly confirm the draft.

For an empty Agent, a repetitive procedure can motivate an installed Skill, an external data source can motivate an Integration, and a missing tool can motivate an MCP server. Ask when the user's stated job gives a reason. A task that already has enough context can proceed directly to review. Present requested dependencies separately from access. Settings owns connections and authorization. **Create** and **Save** explicitly commit the reviewed draft. Cancelling leaves the last saved definition intact.

The upstream response body was unavailable. No rule, activation time, automatic job, automatic Run or English output exists for that attempt.
- In the credential-free regression, the private owner creates the rule through the canonical HTTP admission fixture, the signed event passes the real platform/gateway boundary, and one synthetic inference commits to the matching private Chat. Join the job request identity to the completed Run and its assistant message. Exercise duplicate IDs, an alternate ID for the same message, pause/resume and delayed first delivery of a message from the paused interval. The model response and external Slack API are fixtures.
- Separate baselines on the original code include 41 passing tests across agent-create-recovery, managed-custom-editor-skills, integration-grant-source-postgres and memory-service.
