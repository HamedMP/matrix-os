## Failure and root cause

[Main run 41060072500](https://github.com/HamedMP/matrix-os/actions/runs/41060072500) checked commit `0ac479dcea531efe2c3f367194b4d014ec3c4d82`. Both targets resolved published latest `0.166.0`, fetched exec source, and generated the experimental app-server schema successfully. Step 10 failed at `verifyCodexProviderContracts`' exact latest-version guard because both manifests stopped at `0.165.0`. Protocol comparison had not run at that point. This was an unqualified upstream release, with no evidence that the Hermes merge caused the failure.

Updating the version alone would still fail: the complete app-server bytes and three consumed transitive payload digests changed. This repair records the reviewed exact release after comparing its entire generated schema and exercising the existing consumers. It leaves the verifier and runtime parsers unchanged.

## Complete reviewed delta from 0.165.0

`codex-0166-contract-qualification.test.ts` reverses exactly the following changes and compares the entire remaining JSON tree with the retained 0.165.0 fixture. No existing top-level method variant changed or was removed.

- Three client requests were added: `account/gcp/setup`, `accountSession/list`, and `accountSession/switch`. Their nine new account/session/GCP definitions are not called by Matrix's Codex consumers. The new separate `ModelProviderError` definition describes structured JSON-RPC errors; existing generic RPC error handling remains in place.
- Five OpenTelemetry definitions and optional `ConfigRequirements.otel` were added. Matrix does not send these fields or enable telemetry through this repair.
- Optional fields were added: ChatGPT account `workspaceName`, additional-context `name`, hook metadata `environmentId`, hook-list `threadId`, process-exit `outputDrainTimedOut`, and thread-usage `nativeUsageUsdMicros`. Existing required lists are unchanged.
- `ThreadItem` now declares the existing flat object shape with optional nullable integer `startedAtMs` and `completedAtMs`, both defaulting to null. `imageGeneration` additionally accepts optional nullable string `generationId`. Runner schemas use passthrough; lifecycle text/tool output and artifact publication remain intact.
- `HookRunSummary.sourcePath` references `LegacyAppPathString` instead of `AbsolutePathBuf`. Matrix's Codex consumers do not use this property.
- `CodexErrorInfo` adds `policyCapacityUnavailable`. The production classifier keeps this typed error generic even when its message says `Not logged in`; it does not infer an authentication failure from that text.
- `ReviewDelivery` removes `detached`, retaining `inline`. No Matrix Codex consumer calls `review/start` or sends this enum. This upstream API removal does not require an adapter change for the existing integration.
- Descriptions changed for hook-list `cwds`, network `domains`/`unixSockets`, review-start `delivery`, review response `reviewThreadId`, and fork `attachToSource`. The reconstruction test restores only these known descriptions.
